# Smart Task Scheduler Using Data Structures and Algorithms

A Python-based task management application that schedules tasks according to priority and deadlines using Data Structures and Algorithms.

## Features
- Add, edit, and delete tasks
- Priority-based task scheduling
- Deadline tracking
- Sorting and searching tasks
- Task status management

## Tech Stack
- Python
- Streamlit
- Data Structures and Algorithms

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## DSA Concepts
- Binary Heap
- Priority Queue
- Sorting Algorithms
- Searching Algorithms
- Hash Maps

## Purpose
This project demonstrates the practical application of Data Structures and Algorithms in task management and scheduling.
